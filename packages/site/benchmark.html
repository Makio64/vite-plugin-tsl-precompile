Method and limits

Each scene uses stock three/webgpu. We time the first renderAsync, then 90 warm frames after 40 warm-up frames. Cold time includes TSL generation, pipeline creation, driver work, resource setup and other one-time costs.

Wall time varies by device and browser. Precompiled runs still create and compile WebGPU pipelines. Only matched cold stock and cold precompiled runs can support a speedup claim.

Guaranteed in slim mode: captured materials use embedded WGSL and generated update plans, and NodeBuilder is absent. Compatibility mode validates artifacts but keeps three.js's live compiler authoritative. See the boundary →
