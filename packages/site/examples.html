How these numbers were produced

  1. Each three.js webgpu_* TSL example is loaded in headless Chrome with a deterministic requestAnimationFrame shim.
  2. The capture screenshot is taken against live three.js running the full TSL node builder — this is the golden reference.
  3. The same scene is replayed against three/webgpu/slim using the artifact emitted by this plugin — no node builder ships.
  4. Capture and replay are diffed pixel-for-pixel; PSNR ≥ 30 dB is the “visually identical” gate (ITSD-R standard for human-imperceptible difference).
  5. The load-smoke rate counts every example that runs to first frame without throwing — whether the pixels match or not.
