Integrate vite-plugin-tsl-precompile into this existing Vite + three.js WebGPU app.

Before installing or editing, inspect the package manager, Vite config, renderer,
TSL materials, routes, and current three/@types versions. If the app is not a fit
or exact three@0.185.1 requires an unapproved migration, stop without mutating.

After the fit check passes, use the detected package manager (pnpm shown):
  pnpm add -D vite-plugin-tsl-precompile@alpha
  pnpm add @tsl-precompile/runtime@alpha three@0.185.1 --save-exact
  pnpm add -D @types/three@0.185.1 --save-exact  # TypeScript only
  pnpm exec tsl-precompile-install-skill --json
  pnpm exec tsl-precompile-doctor --json --source src

Replace or repeat --source for the source roots found during the audit.

If npm returns 404, stop because the first alpha is not published; do not
substitute. If the new skill is unavailable in this session, read the linked raw
skill or llms.txt and continue. Use $integrate-tsl-precompile end to end in
compatibility mode. Derive the route/state/render-topology matrix and ask about
inaccessible states. Capture real WebGPU paths, verify and commit a non-zero
artifacts/ set, build, and replay the same matrix in a production WebGPU preview.

Common questions

Does my app qualify?

It needs Vite, WebGPURenderer, and TSL NodeMaterials. WebGL-only, non-Vite, or classic-material apps need a migration first.

Prefer doing it manually?

Install pnpm add -D vite-plugin-tsl-precompile@alpha and pnpm add @tsl-precompile/runtime@alpha three@0.185.1 --save-exact, add tslPrecompile() to your Vite plugins, and call setupPrecompile({ renderer }) once. Direct NodeMaterial constructors are detected automatically; explicit material.precompile('hero-body') calls are optional stable-name overrides. Follow the no-AI BYO guide, or use the agent skill.

Backgrounds, PMREM, post-processing, MRT, compute?

Capture auxiliary paths after the scene and post-processing graph are assembled, with setupPrecompile({ renderer, scene, camera, aux: true }) and setup.captureAux({ postProcessing }). See the advanced capture checklist.
