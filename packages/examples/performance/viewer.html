What the numbers mean

Shader nodes counts unique nodes processed by Three’s node builders, including auxiliary passes. It is separate from scene objects and is cumulative through the selected variant. Zero means no nodes were processed by a builder; runtime node objects and binding updates can still exist. The browser still compiles WGSL into GPU pipelines.

Cold first visit runs from navigation to the first completed GPU frame, including module loading, renderer initialization, assets, PMREM and pipeline setup. First render CPU includes lazy GPU pipeline creation inside that draw. The final GPU queue wait includes unfinished setup work, such as PMREM, and driver compilation needed by the draw. The first-visit result uses the initial variant. The pipeline API timing measures the JavaScript call; driver compilation can continue during the GPU wait.

CPU / GPU per frame is the median of warmed frames. GPU time comes from WebGPU timestamp queries, including the scene’s render passes. Precompilation removes runtime graph compilation; it does not reduce the scene’s pixels or triangles.

JavaScript sizes sum all emitted JavaScript files, excluding models and textures. Brotli 11 is the precompressed JavaScript size. First-visit transfer also includes models, textures and HTTP headers.

Small differences can be noise. The live panes are for inspection; the numbers were measured sequentially, with the other renderer closed.
